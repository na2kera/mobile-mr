Mobile MR Demos

スマホでデモを選んで VR ゴーグルへ

  • 01. Stereo Box
    Phase 1: 左右2眼レンダリング + ジャイロ頭追従
  • 02. Passthrough
    Phase 2: 背面カメラ映像を背景にした Passthrough MR
  • ex2-1. Joy-Con RC
    番外編: Bluetooth 接続した Joy-Con で 3D 空間のラジコンを操作
  • 03. Marker Anchor
    Phase 3: ArUco マーカーを World Origin にした現実固定
  • 04. Shared Room
    Phase 4: マーカー共通座標系で相手の位置にアバターを表示（2台で同じ room へ）
  • 05. Hand Interaction
    Phase 5: MediaPipe の手トラッキングで、仮想ボールを押す・ボタンを押す・ 指差しで的を選ぶ
  • 06. MR Volleyball
    Phase 6: マーカーを挟んで向かい合い、手で仮想ボールを打ち合う（1台なら bot と練習。2台で同じ room へ）
  • 06-2. MR Darts
    Phase 6-2: 壁のマーカーに仮想ダーツボード。手を振って投げ、何人でも順番に 3 投ずつ （同じ room に入った端末で手番・得点・刺さったダーツを共有）
  • 07. Surface Mapping
    Phase 7: 壁のマーカーを原点に「Surface」を定義し、指差しで UV 座標を指してペイント。 Surface ID + UV で全員が同じ場所を見る（Phase 8 スプラトゥーンの土台）
  • 08. MR Splatoon
    Phase 8: 四方の壁と床の箱型コートに、パーの間、手からインクを連射。 全員が自分の色で塗り合う個人戦（サーバー権威の格子で共有）
