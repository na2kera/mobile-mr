08-3. MR Splatoon（アウトサイドイン）

08 と同じ仕様のスプラトゥーンを「位置の取り方」だけ変えた比較用デモ（docs/space-stability-options.md の 2a）。 スマホはマーカーを検出しません。部屋に固定した PC の Web カメラ（俯瞰画面の「トラッカー」）が 各ゴーグル前面に貼ったマーカー（ID は入室順に割り当て。入室後の案内と HUD の track=id= に出るので、 印刷した該当 ID をゴーグルの前面に貼る。?trackMarkerMm= 既定 60mm）を検出し、部屋座標系での位置をサーバー経由で受け取ります。 回転はジャイロのまま（ヨーはトラッカーの値で緩やかに補正）。コートは PC カメラの座標系に固定されるので、どこを向いてもコートは動かず、 全員が同じ 1 台のカメラで測られるので相手の相対位置が構造的に一致します。 原点は 08 と同じ正面の壁のマーカー（ID 0）で、床（既定 3.0m × 2.5m）を四方の壁（既定の高さ 2.4m）で囲んだ箱型のコートができます。 塗れる空間の大きさと床からマーカー中心までの高さ（実測。既定 1.2m）は俯瞰画面で開始前に変えられ、全員に配られます。 追加マーカーの配置（床など）はトラッカーの原点合わせに使います（スマホは検出しません。枠は配置どおりに描くので、実物と重ならなければ原点合わせがずれています）。 パーを開いている間、手からインクを連射します（目 → 手の向きへ。満タンで 50 発）。 満タンで 50 発ぶんで、空になると撃てません。撃つのをやめると回復します （撃った直後 1 秒は回復せず、約 5 秒で満タン）。 残量はグーで補充している間だけ、手元のインクタンク（グーの手の横、親指側に浮かぶ筒。水位が残量）に出ます（パーで撃っている間は消えます）。 ただし空になるとパーのままでも出て（枠が黄色く脈打つ）、1/4 ほど回復するまで出続けます。

入室したら練習（時間無制限に自由に塗れます。パーで塗る ／ グーで補充: グーにしている間はインクが約 2 秒で満タン）。 対戦は PC の俯瞰画面の「対戦開始」で始まり（カウントダウン ?waitSec= 既定 5 秒）、 1 分（?matchSec=）で塗った面積が最多の人の勝ち（俯瞰画面の「対戦を終了」で途中でも結果に進めます）。 対戦中は視界の上に自分の順位と塗り率が大きく出ます。結果のあと練習に戻ります。 全員が自分の色で塗り合う個人戦（参加順に 8 色を割り当て）。 何台でも同じ URL を開くだけで同じ room に入ります（既定 room: demo。分けたいときは ?room=名前）。表示名は下の入力欄で設定します（?name= での事前指定も可能）。 手が取れないときは画面を押している間、視界の中央へ連射 （PC は Space キー）。05 で較正した手の実寸（例: ?handScale=1.9）は毎回付けてください。

確認の見方: 開始後、俯瞰画面でカメラを開いて原点を確定し、ゴーグルのマーカーを PC のカメラに向けると、壁と床の枠（上にスコアボード）がその場に出ます。 骨格が背景の手に重なったらパーを開くと連射が始まり、自分の色の玉が壁か床に着弾して塗られれば OK。 グーにするとその横（親指側）に自分の色のインクタンクが浮かび、水位が上がっていくのが見えます（パーに戻すと消えます）。 撃ち続けて空になると、パーのままでも枠が黄色く脈打つ空のタンクが手の横に出ます。グーにすると水位が上がり、1/4 ほどで消えます。 どこを向いてもフィールドはその場に残ります。HUD の track= に自分のマーカー ID・品質 q=・トラッカーのヨー・補正 φ・観測の古さ（見失うと "tracked (0.8s ago)"）、 self=（自分の位置）が出ます。俯瞰画面で「対戦開始」を押すと視界に「まもなく対戦開始」と出て、 格子が消えて 1 分の対戦になります（視界の上に「1位 12.3%」のように自分の順位と塗り率）。俯瞰画面の「対戦を終了」で途中でも結果になります。

調整: 表示は 06 と同じ ?fov=auto&eyeSep=0.064&camZoom=0.7。 原点マーカーは ?markerMm=150（印刷ページ markers.html の既定と同じ。room 設定なので全員と俯瞰画面で揃える。手用は handDetW / handSmooth / handLostMs）。 アウトサイドイン固有: ?trackSmooth=0.3（届いた位置へ寄せる係数）&trackLostMs=2000（見失い判定）&yawQuality=0.5（ヨー補正に使う品質の下限）&yawSmooth=0.1（ヨー補正の速さ）。 08 の detW / smooth / markerIntervalMs / lostMs / gravityAlign / fakeMarkers / fakeCamPos はこのデモにはありません（位置合わせは常に水平で、トラッカー側で行うため）。 飛行・時間 ?gravity=4&matchSec=90&waitSec=5 は room 内で一致が必要です （塗れる空間の幅・高さ・奥行きとマーカーの高さは俯瞰画面の入力欄で変えます）。 手元のインクタンクは ?tankPlace=thumb（親指側。pinky = 小指側、arm = 手首の先）&tankH=0.12（板の高さ [m]）&tankOffset=0.09（手からずらす距離 [m]）&tankHoldMs=800（グーの手を見失ってから消すまでの猶予 [ms]）。 空で出したタンクを下ろす残量は ?tankLowUntil=0.25（0〜1）。 従来どおり見えている手のそばに常に出す（手が見えない間は視界の下）なら ?tankShow=always。手が見えないときに視界の下に出さないなら &tankFallback=0。 PC では ?camZoom=1&fakecam=1&autostart=1&name=PC&fakehands=1 で、合成の手がパー → グーを繰り返して撃ち続け （パー 2.5s → グー 2s → 休み 0.5s。&fakeOpenSec=9 でタンクが空になるまで撃つ）、 別ウィンドウで同じ URL を開くと別の色の相手として同じフィールドを塗り合います（裏タブは描画が止まるので別ウィンドウで）。 位置は俯瞰画面のトラッカーから来るので、俯瞰画面を ?room=同じ名前&tracker=1&fakecam=1&fakePlayers=10:-0.5,0,1.5,0;11:0.5,0,1.5,15 で開き （フェイクカメラに ID 10 / 11 のゴーグルを部屋に置く。入室順に 10, 11 が割り当たる）、原点（床のマーカー ID 1 を配置に入れる）を確定すると 2 台の位置が届きます
