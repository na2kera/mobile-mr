06. MR Volleyball

マーカーを印刷して机に水平に置き、マーカーから 0.8m ほど離れてマーカーを挟んで 向かい合ってください。マーカーの真上に仮想のネットが立ち、ボールが自分の顔の前へ ゆっくり山なりに飛んできます（重力は低めの設定）。 顔の前 30〜60cm に手を出してボールに触れると、相手の顔の前へ自動で打ち返します （狙いは自動。手を速く振ると速い球になります）。 落とした側の失点で、マーカーを置いた面（机の面が地面扱い）に落ちると 2 秒後に次の球がトスされます。

1台だけでも遊べます（相手側は bot が返球。たまに落とします）。2台で対戦するときは両方で同じ URL を開くだけです（既定 room: demo。分けたいときは ?room=名前）。 立ち位置（青の側 / 橙の側）はマーカーを見た時点で立っている側に自動で決まり、最初のサーブまでは 反対側へ歩けば付け替わります（試合中は固定）。05 で較正した手の実寸（例: ?handScale=1.9）は毎回付けてください。

確認の見方: 開始後、まず机のマーカーを見ます（視界内の案内が「マーカーを見て」から 変わります）。ボールと骨格が出たら準備完了。マーカーから目を離して見上げても ネット・ボールはその場に残ります（ジャイロで追従。歩くとずれるのでその場で）。 右手は青・左手は橙の骨格が背景の手に重なります。ボールの真下の影で高さが分かります。

調整: ?fov=auto&eyeSep=0.064&camZoom=0.7 が既定。fov は背景と幾何的に整合する値を 自動計算します（実機 + ゴーグルで ≈94°。05 の 135 をそのまま使うとマーカー基準の コートが背景に対して半分以下に縮んで見えます。数値で固定も可）。 ?handScale= は未指定だと 1（未較正）なので 05 で求めた値を付けてください。 マーカーは ?markerMm=100&camFov=106&detW=960&smooth=0.5&markerIntervalMs=100 （手と同居させるため検出は 10Hz に間引き。05 と違い detW / smooth / lostMs はマーカー用で、 手用は handDetW / handSmooth / handLostMs）。 軌道は ?gravity=4&flightSec=1&reach=0.45（重力・滞空時間・狙いの距離）、ネットは ?netW=1.8（幅 [m]）と ?netTop=auto（上端の高さ。頭の高さから自動。数値 [m] で固定可）。これらは room 内で一致が必要です （違う値の端末は入室できません）。当たりの余裕は ?hitMarginXY=0.02&hitMarginZ=0.08（奥行き方向を広めに）。 PC では ?camZoom=1&fakecam=1&autostart=1&fakehands=1&fakeMarkerPx=80&fakeShiftY=190 で、合成の手がボールに触れて bot とラリーを続けるところまで見られます （fakeShiftY でマーカーを画面の下に寄せると自陣側に立つ幾何になります。2 つ目のウィンドウで &fakeShiftY=-190 にすると反対側に立って対戦の経路。同じウィンドウの裏タブは描画が止まるので別ウィンドウで）
