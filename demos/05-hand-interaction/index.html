05. Hand Interaction

開始するとセンサーとカメラの許可を求め、全画面表示に切り替わります。 許可後、スマホを横向きにして VR ゴーグルにセットし、 手を顔の前 30〜60cm に出してください。 カメラに映った手の骨格が重なって表示され、目の前に浮かぶボールを手で押す・ 手前のボタンを指で押す・指差しで遠くの的を選ぶ、の3つが試せます。

手の検出は MediaPipe（約 20MB の wasm とモデル）を読み込むため、 開始後しばらく「tracker=」の表示が loading のままになります。 ボールが灰色のワイヤーフレームの間は読み込み中、実体化したら準備完了、赤なら失敗です。

確認の見方: ボールが実体化したら手の検出の準備完了。装着して前を向き約1秒で HUD が stage=aligned になり、ボール・ボタンが目の前に来ます（出なければ体ごと 90° 以上向きを変えて 3 秒待つと取り直します）。右手は青・左手は橙の骨格が 背景の手に重なります。HUD の R:0.45m は推定した手までの距離なので、実際の距離 （30〜60cm）と比べてください。両眼で見ると骨格が背景の手から少しずれるのは 単眼パススルーの既知の制約です。

調整: ?fov=70&eyeSep=0.064&camZoom=1 は 02 と同じ。手の検出の既定は ?hands=1&delegate=auto&smooth=0.5&detIntervalMs=0&detAdapt=0&detW=0 で、重いときは ?delegate=cpu / ?detW=640 / ?detAdapt=1.5 / ?detIntervalMs=100、 誤検出が多いときは HUD の res= を見て ?maxResidual=、手が映らないときは ?mpCanvas=dom を試してください。?fakehands=1 は iPhone でも使え、MediaPipe 抜きでステレオ表示・向き合わせ・3操作だけを切り分けられます。 PC では ?fakecam=1&autostart=1 で読み込み経路を、さらに &fakehands=1 を足すと台本どおりに動く合成の手で3操作の経路を確認できます
